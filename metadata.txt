It supports POINT, LINE, LWPOLYLINE and SOLID entities, assigns the coordinate reference system selected by the user, preserves the original CAD layer and entity type as attributes, and exports the resulting Point, Line and Polygon layers to a GeoPackage. DXF2GIS requires the Python package ezdxf to read DXF files.
